# Kafelki

Gra: spadające kafelki do klikania, bez dźwięku. Jeden plik `index.html`, działa w pionie i w poziomie.

## Na ekran główny iPhone'a
1. Opublikuj repo jako stronę (GitHub Pages: Settings → Pages → branch `main`, folder `/`) albo wgraj do Cloudflare Pages.
2. Otwórz adres w Safari → Udostępnij → „Do ekranu początkowego".
